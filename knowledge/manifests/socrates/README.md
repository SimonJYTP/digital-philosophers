# 苏格拉底语料导入说明

本目录的十份清单对应用户提供的六个 EPUB。原始文件按作品和版本保存在
`knowledge/source-files/socrates/`，不会进入 Git；清单保存作者归属、版本、权利
说明、R2 对象键、原文定位与解释边界。

## 核心归属原则

苏格拉底本人没有留下哲学著作。数据库中的“苏格拉底知识”来自柏拉图和色诺芬的
古代文学或回忆性呈现，因此：

- 作品标题始终保留 `Plato` 或 `Xenophon`，不写成“苏格拉底著作”。
- 正式片段使用 `QUALIFIED_FIRST_PERSON`，而不是无条件模拟历史本人。
- 《斐多篇》的灵魂与死亡论使用 `THIRD_PERSON_BACKGROUND`，因为成熟形而上学
  可能更多反映柏拉图。
- 同一段话的不同历史译本作为不同版本保存，不能把译词差异冒充原文差异。

## 当前覆盖的 Agent 能力

- 《申辩篇》：无知之知、灵魂照料、省察生活。
- 《克力同篇》：不以伤害报复伤害，以及这一原则的适用边界。
- 《游叙弗伦篇》：定义、因果方向和尤西弗罗困境。
- 《美诺篇》：探究悖论、困惑与引导式提问。
- 《斐多篇》：死亡与灵魂论，但明确标成柏拉图式背景。
- 《回忆苏格拉底》：色诺芬传统中的自知、能力和限度。

## 重新导入

```powershell
npm run db:migrate:local

Get-ChildItem knowledge/manifests/socrates/*.json |
  ForEach-Object {
    npm run knowledge:import:local -- $_.FullName
  }
```

导入是幂等的：相同作品、版本和片段 ID 会被更新，不会重复创建。命令会把源文件
复制到本地 R2 模拟目录，并把书目、版本和片段写入本地 D1。

## 后续扩充建议

1. 补可靠希腊文原版，并按 Stephanus 页码对齐英译。
2. 加入柏拉图《拉刻斯篇》《卡尔米德篇》《高尔吉亚篇》等早期或苏格拉底式对话。
3. 补色诺芬《会饮篇》《申辩篇》，并与柏拉图传统分栏比较。
4. 如加入阿里斯托芬《云》，应标为喜剧性敌对见证，不能作为苏格拉底自述。
5. Project Gutenberg 仅明确文件在美国属于公版；生产发布前仍需核验部署所在地
   法律，也不应向站点访客提供原 EPUB 的直接下载接口。
