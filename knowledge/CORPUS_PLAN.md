# 哲学家语料库建设顺序

所有哲学家共用一个 D1 数据库，通过 `works.philosopher_id` 隔离语料；原著文件则按哲学家、著作和版本分层存入 R2。模板中的片段默认是 `draft`，只有补入可复核原文、译文和定位并完成审核后，才能改为 `active`。

## 第一阶段：已经建立的入口模板

| 哲学家 | 入口文本 | 示例清单 |

## 第二阶段：建议继续扩展

- 孔子：《论语》不同底本与可靠英译、中译注本；必要时加入《史记·孔子世家》等人物资料，但必须标成后出的传记证据。
- 苏格拉底：柏拉图《游叙弗伦篇》《克力同篇》《美诺篇》，再加入色诺芬《回忆苏格拉底》。苏格拉底本人没有著作，数据库中必须保留作者和叙述来源。
- 康德：《纯粹理性批判》《实践理性批判》《判断力批判》《何谓启蒙》《永久和平论》以及有明确日期的书信。
- 黑格尔：已接入《精神现象学》《逻辑学》两卷、《哲学全书·逻辑学》《哲学全书·精神哲学》《哲学史讲演录》第一卷和《美学》第一卷；下一步优先补《法哲学原理》。讲演录已标为 P2 编订文本，不与亲自出版的著作等同。详见 `knowledge/manifests/hegel/README.md`。
- 尼采：《善恶的彼岸》《快乐的科学》《查拉图斯特拉如是说》《偶像的黄昏》及有可靠年代的书信。遗稿必须记录编辑史，不能无条件当成最终立场。

## 审核原则

1. 原文定位必须能由另一位编辑复核。
2. 解释性摘要和原文引语分开存储。
3. 现代译本和数字版本必须分别核验版权。
4. 作者身份复杂的材料使用 `QUALIFIED_FIRST_PERSON` 或 `THIRD_PERSON_BACKGROUND`。
5. 有争议、转述、讲演整理或后出传记材料，先保持 `draft`。
